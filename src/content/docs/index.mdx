## Quick Start

```bash
# Create a new app
lein new zenthyr my-app
cd my-app

# Run the JVM backend + JCEF window (starts Vite during development)
lein run
```

## What You Get

Zenthyr is a Clojure library (plus a Leiningen template) for building desktop applications with:

- A JVM backend that stays in control of your app
- A modern web UI rendered in a JCEF (Chromium) window
- A tight dev loop powered by Vite hot reload
- Frontend templates for React (default), Vue, Svelte, and Angular
- IPC implemented using JCEF’s `cefQuery` (CefMessageRouter), not WebSockets
